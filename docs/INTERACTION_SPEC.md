# ClipForge 统一交互与功能规范

> 版本：v1.0（2026-09-24）
> 适用：快速面板 / 详情工作区 / 设置窗口 / 引导页
> 依据：docs/DESIGN_SYSTEM.md，本文只规定交互行为，视觉 token 以设计系统为准。
> 每次交付前必须跑 `bash scripts/run-interaction-tests.sh`，全部 PASS 才能交付。

---

## 1. 悬浮窗适配（硬性）

| 规则 | 标准 |
|---|---|
| 面板宽度 | 320–480px 全程可用，任何子树不得超出视口宽度 |
| 高度 | 400–640px，超出部分列表内部滚动，面板本身不滚动 |
| 文本 | 所有行文本必须 truncate 省略，禁止顶到面板边缘 |
| 触发器 | grid/flex 子项必须可收缩：`min-w-0` + `minmax(0,1fr)`，禁止固定宽列撑破布局 |
| 验证 | 320 / 420 / 480 三档宽度走查，DOM 中不得出现 `width > innerWidth` 的元素 |

## 2. 反馈三件套（统一标准）

| 反馈 | 用途 | 规范 |
|---|---|---|
| **Toast** | 操作结果（复制/收藏/删除/导出） | 单行小胶囊（12px 字、6×12 padding、圆角 8px），**1.4s 自动消失**；先完整可见再淡出，禁止瞬消；禁止大图标 + 多行描述 |
| **Tooltip** | 行内容预览 / 图标释义 | 内容超宽或靠近边缘时走 portal 挂载 body，位置 clamp 在视口内；hover/focus 显示，移出即消 |
| **StatusBar** | 常驻状态行 | 底部栏单行 truncate，自定义状态优先于默认导航提示 |

## 3. 图标按钮规范

- 顶栏 scope 按钮：统一 28px 圆形命中区，图标统一 15px。
- 激活态：浅灰填充 `bg-black/[0.08] / dark:bg-white/[0.12]`，**禁止实心黑块**。
- 非激活：透明底 + hover 浅灰；禁用：40% 透明 + 禁手型。
- 所有图标按钮必须有 `aria-label` 与 tooltip 释义。

## 4. 页面结构规范

### 4.1 主面板

搜索栏（52px）→ 列表 → 底栏（36px）。列表行高 34/40/44px 随密度；行内操作hover 出现，序号常态显示。

### 4.2 详情页

- 面包屑头：返回 + 标题 + 上一条/下一条 + 编辑 + 溢出菜单 + 关闭。
- **主内容直出**：打开详情即见类型化预览（文本/代码/Markdown/JSON/链接/图片/文件），不做折叠。
- 链接：chip 行（icon + 截断标签），点击新窗口打开。
- 采集上下文：默认折叠的 accordion，内部可一键复制 JSON。
- 编辑态：快捷编辑器替换内容区，保存/取消前未保存改动需确认。
- 底色透明（跟随 `.material` 材质），禁止不透明底色盖住面板。

### 4.3 设置窗口

- 侧栏单项单行：icon 13px + 文字 truncate，禁止换行；侧栏宽 200px。
- 内容区行式表单：label 13px 左、控件右；窄窗下控件换行不挤压 label。

## 5. 快捷键（主面板）

| 键 | 行为 |
|---|---|
| ↑↓ | 移动选中 |
| ⏎ | 粘贴选中条目 |
| 空格 | 快速预览卡 |
| ← / → | 工作区返回 / 下钻详情 |
| / 或任意字符 | 聚焦搜索 |
| t | 回收站视图 |
| ⌘F / ⌘P / ⌘J | 收藏 / 固定 / （预留） |
| ⌘A / ⌘C / ⌘X | 全选 / 复制 / 删除 |
| ⌘1–9 | 按序号粘贴 |
| Esc | 关闭浮层 / 退出 |
| ⌘, | 设置 |

## 6. 数据与降级

- 浏览器预览走 `src/services/tauri-web-mock.ts`（dev-only），与 Rust 同名同参命令协议；三个入口（main/settings/onboarding）第一行必须导入。
- 剪贴板 API 不可用时写回静默降级，功能路径不得中断。
- 每条 invoke 失败必须落 `append_app_log`，用户可见错误走 `formatCommandError` 的 `CODE: detail` 协议。
