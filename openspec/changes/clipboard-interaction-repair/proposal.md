# 提案：剪贴板详情与多选交互修复

## 背景

2026-11-05 验收发现详情编辑入口、富文本、导航、错误反馈、多选、收藏详情和标签交互存在问题。先保护剪贴板内容与快速粘贴，再按统一交互修复。方案已与用户逐项确认。

> **实现状态（2026-11-25 对账登记）**：八项修复的代码已在工作区落地；10 个 checkbox 仍未勾选（按项目「不代勾」铁律由人工验收后勾选）。2026-11-25 补齐此前未闭合的缺口：详情正文编辑不再把标签写回伪造成内容更新（`updateClipContent` 改为 `updateClipTagsOnly`）；收藏等视图统一走 `QuickPastePanel`，行内 + 右键详情入口对小屏与收藏视图均可见；多选空格/Cmd+A/C/X/Tab/Escape/`/` 与右键菜单按 `contextMenu.item` 绑定；CSV 与按类型分割导出统一在写盘前经 `buildCheckedSources` → `checkFilePaths` 复核，不再依赖列表加载时的陈旧状态。新增 `scripts/verify-multi-select-interaction.mjs`、`scripts/verify-favorites-detail.mjs` 并挂入 `pnpm test:unit`。已跑 `pnpm build:web`、`pnpm test:unit`、`cd src-tauri && cargo check`、`openspec validate --all --strict`；`pnpm build`（重签发布产物）、`pnpm tauri dev` 与沙箱实机八项走查仍未验证。

## 现状、期望与验收

| 项目 | 现状 | 期望 | 验收标准 |
| --- | --- | --- | --- |
| 1. 编辑入口 | 编辑按钮处于底栏末端，窄窗口可能挤出；图片和文件不可编辑 | 入口位置固定，始终清晰可见；不可编辑类型明确禁用原因 | 不同窗口宽度下可编辑条目均可进入编辑，图片和文件不误导可编辑 |
| 2. HTML 与 Agent 编辑 | HTML 在隔离预览中展示，编辑器为 Markdown 文本框；现有保存可能重建 representations | 安全渲染并以轻量 React 富文本方案编辑，与 Agent 草稿及差异确认兼容 | 格式化内容可渲染和编辑；保存前展示差异；原始内容可恢复；编辑后复制格式与正文一致；仅改标签不破坏原格式 |
| 3. 上下按钮 | 详情标题栏按钮样式不协调；切条目可能丢弃未保存草稿 | 按钮样式一致；离开有未保存内容的页面先确认 | 上下切换、返回、关闭均保护正文、标签与 Agent 草稿；保存中不能丢失内容 |
| 4. 错误与修复 | OCR 错误被截断，提示缺关闭入口和明确处理步骤；常驻原因待复现；Agent 仅有只读工具 | 显示明确原因及脱敏修复方案，允许关闭、复制；Agent 提出真实可执行的修复并在执行前确认 | 错误可关闭、可复制且不泄露凭据；本地端点不可达时可诊断并给出具体步骤；经确认才修改配置或启动已识别服务，失败原样反馈 |
| 5. 多选与导出 | Space 在普通模式打开预览但提示称选择；选区与操作数量可能不一致；表格仅复制，分割导出仅文本 | Space 在列表选择；筛选仅保留可见选区；未选中项右键不改变选区；支持详情、表格及按类型分割导出 | 键盘焦点不影响输入和菜单；选区数量与操作一致；表格可复制或导出 CSV；文本、图片和文件分别导出，缺失项明确报告 |
| 6. 收藏详情 | 收藏复用普通列表，单击粘贴；用户反馈无法进入详情，具体触发原因待实机复现 | 收藏条目拥有清晰、可用的详情入口 | 收藏视图经详情入口和键盘能打开正确条目，返回仍处收藏视图，不破坏单击粘贴 |
| 7. 交互一致性 | 焦点、菜单及快捷键存在冲突，Tab 等按键路由范围需核对 | 统一列表、详情、输入和菜单的交互边界 | 输入、按钮和菜单保留原生键盘行为；列表快捷键只在适当上下文生效，回归测试覆盖冲突 |
| 8. 智能标签 | 标签点击搜索；添加、删除需进入正文编辑态 | 保留点击搜索，提供直接添加和编辑入口 | 浏览态可增删标签并保存；已有标签来源信息保持正确；正文及原格式不受影响 |

## 范围与约束

- 与 `detail-page-information-architecture`、`clipboard-multi-format-fidelity`、`file-image-clipboard-support`、`ocr-image-text-extraction` 衔接；不以历史任务勾选代替本提案验收。
- HTML 及其他剪贴板内容来自不可信来源，渲染保持隔离；富文本变换不能静默丢弃原始内容或其他格式。
- 富文本正文保存和恢复须以数据库事务保留原始内容及全部 representations；只改标签不得重建正文或 representations。编辑后的 HTML、纯文本和全文索引保持一致；旧 RTF 保存在可恢复快照，不冒充修改后的格式。保存失败或内容并发变化不得覆盖原数据。
- 筛选范围指符合当前筛选条件的已加载条目，而非虚拟列表视口；滚动或追加分页不得移除选区。右键未选中项的菜单仅操作该项，已选中项的菜单操作选区，删除、复制和导出均遵循同一规则。
- 分割导出不覆盖已有文件，图片和文件复制原始文件而非路径文本；缺失、目录和部分失败须明确报告。CSV 处理逗号、引号、换行与表格公式注入。
- 诊断展示、复制、日志和发送 Agent 之前脱敏；用户确认前不执行修改配置或启动服务的动作。调用可能收费或外发信息的模型，须先说明 provider、外发内容、成本与次数并取得授权；模型安装和下载需另行取得授权。
- 按沙箱验证，不动稳定版数据；不将图片 OCR 发送云端。
