真实场景预演 → v1 痛点 → v2 对策

场景v1 预演结果v2 对策
S1 看完即复制复制钮在底部，视线从内容跳到窗口底端再回来内容右上 sticky 迷你工具（复制/全选/字数）＋ 详情页聚焦时 ⌘C 直接复制回写
S2 键盘翻最近几条无键盘翻条目；切条目内容高度跳变、滚动位置丢失↑/↓（或 J/K）翻条目，140ms 方向感知过渡；meta 行高度锁定 + 每条目滚动位置记忆
S3 收藏常用片段详情页无收藏入口（现状 favorite 只在列表层）crumb 右侧 ☆ toggle（F 键），收藏态高亮
S4 删除错剪条目详情页无删除入口，需回列表溢出菜单底部「删除」红字危险区（与来源/上下文分组隔离）
S5 摘要与内容对照AI 摘要 overlay 从底部滑入，盖住内容尾部；来回开关打断阅读默认内联展开（推挤内容不遮挡）；需要钉住对照时一键转 overlay 并保留
S6 不同类型不同动作底部动作区 4 钮固定，图片/JSON 特有动作无位类型槽位：图片→另存为/复制图片；JSON→折叠全部/复制格式化；与插件 detail-action 同一套 match 声明
S7 顺手清 tag改 tag 必须进整页编辑器chip 悬停显 ✕ 单删；行尾 ＋ 快速加；provenance 色点显示来源
S8 大图查看图片只能被动适配图片态迷你工具切换 适缩/实际尺寸；动作区出「另存为」
v2 未动 v1 骨架：五区布局、meta 单行、底部动作区、renderer registry、tag 四源全部保留；只做场景层强化。
键盘位注记：⌘C 复制回写 / ↑↓ 翻条目 / F 收藏 / E 编辑 / Esc 返回列表——以按钮 tooltip 形式可见可发现。
