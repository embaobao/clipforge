批注v3 落法
「详情 · 文本」没意义，点击应能看采集原数据crumb 标题位换成「ⓘ 采集原数据」入口：点击原地展开下钻层，全量展示采集字段（source_app / bundle_id / process / 采集时间 / 事件上下文 / 完整 metadata），底部动作区不再挤采集上下文入口
直接进下钻页编辑，不放下面，更沉浸，保存等抽离到下钻页编辑改为下钻层（原地覆盖内容区，slide-up 240ms）：整幅 textarea + tag 编辑行 + 底部「保存 ⌘S / 取消 Esc / 保存并粘贴」；底部动作区编辑钮只是入口（快捷键 E），保存/取消动作全部抽离到下钻页，动作区恒定 40px
↓ 箭头（翻条目）联动crumb ↓ 即翻下一条（本演示里点击 ↓ 会切换到 JSON 条目再切回，演示方向感知过渡），键盘 ↑/↓/J·K 同源
AI 场景没有演示右上 stage 切换器演示四态：分析前（动作区 AI 钮常态）→ 生成中（dashed 边框 + 呼吸点 + 可取消）→ 结果（内联摘要 + 建议 tag + 应用/钉住）→ 已应用（success 确认条 3s 自动收起 + chip 色点变绿）→ 失败（红条 + 重试）。中断演示：生成中切换条目，请求代际失效自动丢弃

左栏 v2 保持静态参照；右栏可完整点：ⓘ 原数据、✎ 编辑下钻（改内容保存回写）、AI 四态、↓ 翻条目。
