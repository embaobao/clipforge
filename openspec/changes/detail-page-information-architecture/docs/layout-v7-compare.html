批注v7 落法
不要侧拉了；详情页编辑状态下直接编辑 tag、文本等内容侧推面板 + 自带 MD 编辑器整体删除。详情页三态：浏览（只读）→ 编辑（内容区即编辑器，textarea 满高；tags 行内编辑：× 删、输入加）→ diff（插件草稿对比）。E/双击进入编辑，⌘S 保存生效，Esc 不保存退出
AI 插件区域放 tag 右边插件区从底部动作区上移至 tags 行右侧（虚线分组恒定可见）；底部动作区只剩 复制/粘贴/编辑 与状态化按钮，更干净
AI 按钮支持下拉；自定义功能支持绑定快捷键和 id、定义触发时机⌕ AI = 下拉：自定义功能列表（名称 + 稳定 id + 快捷键），配置弹窗可改绑快捷键、选触发时机（手动/进入详情时/保存前）、启用开关；id 是插件注册的稳定标识，Agent 可写入
插件队列下拉内「插件队列」+ ⌕ 钮角标：显示运行中（spinner）/排队中/完成态，并发上限 2；完成产出自动路由——改内容 → diff 态，标签建议 → 追加到 tags
触发详情页 diff 效果；保存即生效，不保存就退出插件改写类产出在详情页内容区直接呈现红删绿增 diff + 草稿横幅（来源 id）；草稿不落库：⌘S 保存生效回浏览态，Esc/放弃 丢弃草稿。编辑态与 diff 态共用同一「保存即生效 / 退出即弃」模型
尽量保证完整编辑器的显示状态编辑态隐藏浏览态正文与提示行，textarea 占满内容区（含自动增高与字数状态行）；顶部 chips/插件区仍可用，编辑中可随时唤起插件（如推荐标签）直接并入草稿
v7 完整交互设计（终版候选）：
状态机 浏览 ⇄ 编辑（E/双击 ↔ ⌘S/Esc）· 浏览 → diff（插件产出/编辑中调用插件）→ 浏览（⌘S 生效 / Esc 弃）· 弹窗层仅两处：采集原数据、AI 功能配置。
一处一操作 复制=底部主钮 · 编辑=底部 ✎/E · 类型快速操作=类型 chip 下拉 · 采集原数据=来源 chip · 插件功能=tags 右侧 ⌕ 下拉 · 深层配置=设置页。
插件契约（宿主侧） 功能=稳定 id + 名称 + 快捷键（可绑）+ 触发时机（manual/on-enter/on-save）+ match 类型；改写产出走 diff 草稿协议，标签产出走建议-点选协议；队列并发 2。细节归 agent-plugin-runtime 提案，本提案定义落位与协议。
tag 规则 内置规则设置页显式开关（#多行 删除，lib.rs L4953-4955）；自定义规则 Agent 可写入（tag_rules + provenance）。
