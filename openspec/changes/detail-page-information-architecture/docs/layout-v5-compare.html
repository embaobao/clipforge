批注v5 落法
功能不要在一个操作位显示多个一处一操作铁律：复制只在底部主钮；编辑只在底部 ✎（E）；AI 只在插件区 ⌕；类型操作只在编辑弹窗工具行；采集原数据只在 chips。v4 的边界条注入位、编辑器内 AI 润色全部删除
不要二级面包屑分层，直接弹窗关闭就好取消下钻层与侧拉面板两种自造容器；原数据/编辑/AI 统一为居中 modal：点击遮罩、Esc、✕ 三种方式关闭，无层级嵌套、无返回栈
AI 插件放统一插件集成区，不注入编辑底部动作区新增「插件」带（虚线框视觉分组）：AI ⌕ 是第一个插件钮，后续 detail-action 全落这里；manifest 仍声明注入类型，但注入位=插件区（按当前条目类型决定插件钮是否可用/可见），编辑弹窗内零注入
样式与交互细节优化统一圆角/阴影/spacing 标尺（10-14px 圆角、三级阴影）；按钮统一 30px 高 + active:scale 反馈；toast 统一操作反馈（替代按钮内状态变化）；chips 悬停 chev 微动效；键盘提示行常驻内容底部（可发现性）；焦点态 2px outline
v5 操作规范（终版候选）：
① 全局动作（复制/粘贴/编辑）→ 底部动作区，恒定 3 钮 + ⋯；② 插件动作 → 底部「插件」带统一入口（AI 首发），按类型可用性禁用；③ 深层信息（原数据/AI/编辑）→ 居中弹窗，Esc/遮罩/✕ 即关，无分层栈；④ 采集信息 → 顶栏 chips 即入口；⑤ 类型操作 → 编辑弹窗内工具行（打开编辑才有）；⑥ 所有反馈走 toast。
相比 v4 删除的：内容边界工具条、编辑器注入位、AI 侧拉面板、下钻层容器——功能不减，容器收敛为「顶栏 + 内容 + 底部 + 弹窗」四种。
