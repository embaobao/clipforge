tag 默认规则回填设置；#链接/#工作/#Markdown/#多行 生成得怪、用户不需要；可由 Agent 配自己的规则；#多行 规则删除tag 规则整体回填设置页「标签」分区：内置规则改为显式开关列表（链接/Markdown 等每条可单独关），#多行 规则删除（src-tauri/src/lib.rs L4953-4955 已定位待删）；自定义规则（正则/关键词）写入 tag_rules，支持 Agent 代配置并带 provenance
上下箭头 icon 粗糙丑翻条目换 1.6px stroke chevron SVG（16px 网格），收藏换线框五角星，返回换 chevron-left，全站 icon 统一 lucide stroke 风
类型 chip 点击应是下拉快速操作（当前类型 + 自定义触发配置），不是原始数据类型 chip = 下拉菜单：文本（智能识别格式/大小写/去空白/转 Markdown）、JSON（折叠全部/复制格式化/复制压缩/校验）、图片（适缩/另存/OCR），底部「配置此类型的操作…」进设置；采集原数据入口唯一归来源 app chip
编辑保留之前样式不要改编辑恢复 v3 下钻层：slide-up 覆盖内容区，层内底栏 保存(⌘S)/取消(Esc)/保存并粘贴，样式未动
AI 侧拉不要遮挡；引入 MD 编辑器；能 diff；快捷操作AI 改侧推：面板右滑进入同时主内容 flex 缩窄，不叠不遮；面板内 MD 编辑器（B/列表 快捷工具行）+「编辑/对比」tab，对比为红删绿增 diff 视图；流程 = 生成润色 → 对比 diff → 回写内容
v6 操作规范增量：① 类型 chip → 下拉快速操作（类型专属操作 + 配置入口）② 采集原数据 → 只在来源 app chip ③ 编辑 → v3 下钻层（不改）④ AI → 侧推面板（不遮挡）+ MD 编辑器 + diff 视图 + 快捷工具行 ⑤ tag 内置规则 → 设置页显式开关（#多行 删除），自定义规则支持 Agent 写入。
