批注 → v4 吸收

批注v4 落法
类型/Safari 两个 chip 上移，本身就是采集信息，点击直接看原始信息；不要「采集原数据」文字钮类型 + 来源 app chips 上移进 crumb 顶行，chip 即入口（▾ 提示可点）；点击原地展开采集原数据下钻层（source_app/bundle_id/process/时间/事件上下文/hash 全量）；独立 meta 行取消，只剩 tags 薄行
AI 不放底部，类似详情页插件，唤起侧拉；不占主内容区AI 定位为第一个内置插件：侧拉面板（右侧 64% 宽浮层，可打断滑入，主内容不被挤压）；入口 = 编辑器边界工具条的插件注入位 ⌕（manifest 声明注入类型，设置可关）；底部动作区不再有 AI
AI 插件支持配置：识别图片/概览文字/优化提示词/推荐标签/快速回写/生成预览侧拉面板内直接见能力开关 + ⚙ 展开提示词模板编辑（{{content}}/{{kind}}/{{tags}} 变量）；完整配置落设置页「AI 分析插件」分区（同一 schema，mock 即真实结构）；快速回写演示：生成预览 → 回写内容
JSON/文本类操作不放底部，内嵌编辑器边界操作规范三层：全局动作（复制/粘贴/收藏/返回）→ 顶/底固定区；类型动作（折叠全部/复制格式化/另存为）→ 内嵌内容区边界工具条（sticky 跟随滚动）；插件动作 → 边界工具条注入位 + 下钻编辑器边界注入位。底部动作区恒定只剩全局动作
AI 整体功能就是一个插件，支持配置在不同类型注入 icon 操作按钮，默认可触发AI 以 detail-edge-action 注入位示范：文本/JSON 条目边界条出 ⌕，图片条目可配成「识别图片摘要」（本 mock 三态均注入）；插件注入按钮与类型按钮同 24px 语言，dashed 边框区分来源
操作规范（v4 定稿核心）：
① 全局动作（复制/粘贴/收藏/删除/返回/翻条目）→ crumb + 底部动作区，恒定不变；② 类型动作 → 内容区边界工具条 sticky 内嵌，随 renderer 走；③ 插件动作 → 边界条/编辑器注入位（manifest match 声明），AI 是第一个示范插件；④ 编辑 = 下钻层（E/双击），保存/取消/保存并粘贴在层内；⑤ 深层信息（采集原数据/AI）= 下钻层或侧拉，不占主内容。
